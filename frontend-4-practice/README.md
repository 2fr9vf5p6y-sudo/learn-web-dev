# BRUTAL CUT — практика №4

Страница выбора даты и времени на React с дизайном и компонентами из `frontend-3-practice`. Данные приходят с имитационного сервера Vite.

## Запуск

Из папки `frontend-4-practice`:

```sh
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://localhost:3000).

```sh
npm run build
npm run lint
```

`build` проверяет и собирает клиент. Mock API подключён через `configureServer`, поэтому для работы календаря нужен `npm run dev`; `vite preview` сам по себе API не запускает.

## Реализация

- `App.jsx` получает серверную дату через `fetchToday` в `useEffect`, показывает загрузку, ошибку и кнопку повторной попытки.
- `BookingPage` хранит выбранную дату, месяц, год и время в `useState`. При смене даты очищает время и запрашивает слоты через `fetchSlots` в отдельном `useEffect`.
- `src/api.js` обращается к `GET /api/booking/today` и `GET /api/slots?day=&month=&year=`, проверяет `response.ok` и передаёт ошибки компонентам. Месяцы нумеруются от 0.
- Очистка эффектов отменяет запрос через `AbortController`; флаг активности дополнительно не позволяет устаревшему ответу или ошибке обновить состояние. Дата ответа слотов также сверяется с запрошенной.
- Прошедшие дни определяются относительно даты сервера. Занятые слоты недоступны. Кнопка «Далее» активна только после выбора времени.
- Перелистывание прошлого месяца оставляет дату невыбранной; текущего — выбирает серверное «сегодня»; будущего — первое число.
- `Calendar`, `TimeSlots`, `BookingSummary`, `Header` и `Footer` используют JSX, `.map()` и обработчики React.

`server/server.js` и `vite.config.js` сохранены без изменений. Исходная серверная дата — 17 октября 2026 года; она не зависит от часов компьютера.

## Проверка сценариев

Проверено в браузере:

1. Начальная загрузка даты и слотов, выбранное серверное «сегодня».
2. Выбор свободного времени и обновление карточки с днём недели, датой и годом.
3. Сброс времени, загрузка и обновление слотов при смене дня.
4. Недоступность прошлых дат и занятых слотов, переход через границу года.
5. Быстрое переключение дней с ответами в обратном порядке: остаются данные последней даты.
6. Ошибки загрузки даты и слотов, повторные попытки, HTTP-ошибка с не-JSON телом.
7. Пустой список слотов и мобильный экран шириной 390 px.

Ошибки и задержанные ответы проверялись перехватом запросов в браузерном тесте без изменения mock-сервера.
